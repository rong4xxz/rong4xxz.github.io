# What？
这是2026年6月26日上海人工智能实验室联合中国科学技术大学、复旦大学、香港中文大学等，于 arxiv 发表的一篇论文《[Parametric Skill](https://arxiv.org/abs/2606.30015)》提出的新思路，可以类比为，之前的 skill 相当于说明书，当需要用到相关知识的时候，去读一遍。但是参数化技能通过训练一个小的 Adapter，插入后，使得这个 skill 变成 LLM 的“肌肉记忆”。

# Why？
现在的文本式 skill 有两个根本问题 ：

1. **模型读不懂**：开源模型（尤其是小模型）很难完全理解和遵循复杂的文本 skill 指令，特别是在长上下文场景中，关键指令容易丢失
2. **skill 进化和模型学习脱节**：文本 skill 的优化（如 EvoSkill、CoEvoSkills）是在文本空间重写，模型本身没被优化

# How？
## 核心思想
**核心思想：把 skill 从"文字"变成"权重"**

+ 传统文本 skill：SKILL.md（几千 tokens）→ 模型读文字 → 理解 → 执行
+ 参数化 Skill：SKILL.md → Hypernetwork → LoRA adapter（几十 KB）→ 插到模型上 → 直接执行

**关键区别**：模型不需要"读"Skill 了，Skill 的能力直接变成了模型的一部分权重。

## 具体步骤
1. 构建 skill 库
- 从网上爬取 skill（大部分 skill 的来源）
- 从真实 Agent 轨迹中总结 skill（通过LLM自动化完成）
- 共 **45,800** 个 skill，覆盖 13 个领域（软件、AI/LLM、安全等）
2. 合成训练数据

用 **OpenCode** 沙箱围绕这些 Skill 合成单轮/多轮 Skill 利用轨迹。

3. 训练 Hypernetwork[^1]
- 输入：文本 Skill（SKILL.md）
- Hypernetwork：基于Qwen3-8B
- 输出：LoRA Adapter（参数化 skill）

训练分**三个**阶段：

- **预训练**：让 Hypernetwork 学会把文本 Skill 压缩成参数
- **单轮微调**：学会利用 Skill 完成简单任务
- **多轮微调**：学会在复杂交互中利用 Skill

# 关键发现
研究发现，参数化 skill 是可以**累积**的，也就是说可以把多个 skill 的经验合并为一个全局的参数化 skill，这是**持续学习**的初步方向

[^1]: Hypernetwork 是一种**用神经网络生成另一个神经网络权重**的技术。它自己不直接去做任务，它“生产”做任务的神经网络
