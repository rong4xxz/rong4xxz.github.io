# Agent 的前世今生

想要弄明白 Agent 为什么突然这么火，到底强在哪里，又弱在哪里，需要了解 Agent 的前世今生。首先要从前 Agent 时代开始讲起，也就是 LLM 时代！

## 一、前 Agent 时代

**时间点**：2022年底-2023年中（ChatGPT爆火后、LangChain成熟前）

**认知**：LLM就是一个“超级强大的文字接龙模型”。你要让它做任务，唯一的接口就是**写提示词**。

**这个阶段大家在聊的都是 Prompt Engineering **，提示词工程解决了哪些问题呢：

- 怎么让模型“一步步思考”（Chain of Thought, CoT）
- 怎么让模型扮演某个角色（“你是一位资深HR……”）
- 怎么格式化输出（JSON、Markdown表格）
- 怎么避免幻觉（“如果不知道就说不知道”）
- 怎么少样本学习（给几个例子，few-shot）

**代表性技术**：Zero-shot、Few-shot、Chain-of-Thought、Self-Consistency、Role Prompting

**这个阶段的局限**：

- 模型只能“输出文字”，不能**行动**（不能查数据库、不能调API、不能执行代码）
- 所有“智能”都挤在一个上下文窗口里完成
- 复杂任务容易崩，因为模型要在一次生成里做完所有推理

**典型场景**：

- “帮我分析这段代码的bug”（输出文字分析）
- “总结这份合同的关键条款”（输出文字总结）
- “写一封给客户的道歉邮件”（输出文字邮件）

**关键词**：**一次性的、纯文本的、无行动的**

## 二、Agent概念萌芽

**时间点**：2023年中-2023年底（ChatGPT Plugins、Function Calling 出现）

**转折点**：模型突然能“调用工具”了。

**此时的 Prompt Engineering 要解决新问题**：

- 怎么让模型决定“该不该用工具”
- 怎么让模型生成正确的函数调用参数
- 怎么处理工具返回的结果
- 怎么在多步调用之间保持状态

**代表性技术**：ReAct（Reason+Act）、Toolformer、Plan-and-Solve、

**这个阶段的本质**：

> Prompt Engineering 仍然是核心，但 prompt 不再是“给模型看”，而是“给模型一个决策框架”。

你写的 prompt 变成了：

```text
你是一个智能体，你可以使用以下工具：
- search(query)：搜索互联网
- calculate(expression)：计算数学表达式

你需要：
1. 思考当前需要什么信息
2. 选择合适的工具
3. 根据工具结果继续思考

用户问题：{question}
```

**关键词**：**决策框架、工具使用、多步推理**

### 小结：ReAct + Plan-and-Solve = 现代Agent的骨架

- **ReAct**：让LLM能“边想边做”，应对未知问题
- **Plan-and-Solve**：让LLM能“先规划后执行”，长期任务不走偏
- **两者结合**：先做Plan，执行中用ReAct，遇到意外反馈修订Plan

这个模式就是现在所有Agent框架（LangGraph、AutoGen、Claude Agent SDK）的共同底层逻辑：
> 高层做规划（Plan），低层做执行（ReAct），状态管理做衔接（记忆/文件/git）。

## 三、成熟Agent时代

**时间点**：2024年至今（Claude 3、GPT-4 Turbo、各种Agent框架成熟）

**认知转变**：

> Prompt Engineering 不再是“写一段话给模型”，而是**设计一个“决策系统”**——模型自己写 prompt 给自己，或者系统动态调整 prompt。

**这个阶段的 Prompt Engineering 形式**：

1. **Agent 自己写 prompt**：
- Agent A 拆解任务，为 Agent B 生成专用的 prompt
- 例如：主Agent说“你去查一下今天的天气”，然后动态生成一个“你是一个天气查询专家……”的 prompt 给子Agent
2. **System Prompt 变得极其复杂**：
- 不再是“你是一个助手”，而是几百行伪代码
- 包含：可用工具列表、决策树、错误处理规则、记忆读写规范
3. **Prompt 变成“可执行代码”**：
- Anthropic 的“提示工程指南”里，prompt 包含 XML 标签、条件判断、循环逻辑
- 例如：`<if condition="tool_result contains 'error'">...</if>`

**代表性技术**：

- **Meta-Prompting**：用LLM来写/优化prompt（对抗三方体：生成器→审计器→优化器）
- **Autonomous Prompt Engineering**：Agent在运行时自己发现prompt问题并自动修复
- **Prompt Optimization**：用算法（进化/搜索/元学习）自动搜索最优prompt

**本质变化**：
> 前Agent时代，人写prompt；Agent时代，系统自己写prompt。

**关键词**：**动态生成、自举、元认知**
