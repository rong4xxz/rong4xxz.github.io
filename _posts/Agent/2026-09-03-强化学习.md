# 强化学习 RL(Reinforcement Learning)

是一种机器学习方法，核心思想是：智能体通过与环境不断交互试错，根据获得的奖励信号来学习最优策略，目标是最大化累计奖励。一句话来说，就像训小狗，做对了给零食奖励，做错了就没有零食/有惩罚，久而久之小狗就学会了如何获取更多零食。

## RL 的核心要素

- Agent：做决策的学习者
- Environment：智能体交互的外部世界
- State：当前环境的观测状态
- Action：智能体可采取的操作
- Reward：环境反馈的得分信号
- Policy：从当前环境的状态到采取的动作的映射规则

## RL 训练流程（循环过程）

```text
1. Agent 观察当前 State
2. Agent 根据 Policy 选择一个 Action
3. 环境执行 Action，返回新的 State 和 Reward
4. Agent 根据 Reward 更新 Policy（目标是让未来奖励更大）
5. 重复 1~4，直到收敛
```

这个循环被称为”试错学习“（Trial and Error）

## RL 与 监督学习、无监督学习的对比

|维度 |强化学习 |监督学习|无监督学习|
|---|---|---|---|
|数据来源|与环境交互生成数据|人工标注的静态数据集|无标签的静态数据|
|反馈信号|延迟的奖励|即时正确的标签|无反馈|
|目标|最大化长期累计奖励|最小化预测误差|发现数据中的模式/结构|
|典型场景|游戏AI、机器人控制、自动驾驶|分类、回归（如图像识别）|聚类、降维（如客户分群）|

## RL 的核心算法分类

- 基于价值（Value-based）：学习状态或动作的价值，选择价值最高的动作
  - Q-Learning
  - DQN
- 基于策略（Policy-based）：直接学习策略函数，适合连续动作空间
  - Policy Gradient
  - PPO
- 演员-评论家（Actor-Critic）：结合上述两者，Actor 选动作，Critic 评估价值
  - A3C
  - SAC
- 基于模型（Model-based）：学习环境模型，在”想象“中规划，样本效率高
  - AlphaGo
  - Dreamer

## RL 训练的难点

1. 奖励设计难：奖励稀疏或设计不当，会导致学不到东西
2. 样本效率低：需要与环境交互数百万甚至数十亿次
3. 探索与利用的平衡：是一直用已知好策略（利用）还是尝试新动作（探索）
4. 训练不稳定：策略更新可能导致性能剧烈波动
