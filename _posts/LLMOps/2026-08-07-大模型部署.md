## python虚拟环境需要安装的依赖

首先创建虚拟环境并激活 `python -m venv venv && source venv/bin/activate`

### 基本依赖

#### PyTorch

这是深度学习领域最核心的计算框架，所有大模型的骨架（神经网络层、张量运算、自动求导等）都依赖 PyTorch 来实现。同时 PyTorch 的版本也很复杂，因为首先有 CPU版、CUDA版，同时针对不同的 CUDA 驱动，也有不同版本，所以在选择安装 PyTorch 的时候需要根据自己的显卡的 CUDA 版本，来决定下载什么版本

`pip install torch==2.8.0+cu128 torchvision==0.23.0+cu128 torchaudio==2.8.0+cu128 --index-url https://download.pytorch.org/whl/cu128`

上面这条命令用于下载指定版本的 torch、torchvision、torchaudio 库

+ PyTorch(torch)：这个库是深度学习引擎，是张量计算、自动求导、神经网络层（如nn.Linear）、优化器（如Adam）等所有深度学习的基础构件。相当于整个房子的地基和钢筋混凝土框架。没有它，什么都建不起来。
+ TorchVision(torchvision)：这个库顾名思义，是计算机视觉工具箱，提供经典模型（如ResNet）、图像变换（如裁剪、归一化）、常用数据集（如CIFAR-10）等，专为图像/视频任务设计。专门负责房子里的“眼睛”和“视觉”部分，比如摄像头系统和图像处理软件。
+ TorchAudio(torchaudio)：顾名思义，这个库是音频与语音处理工具箱，提供音频I/O、常用变换（如频谱图）、预训练模型（如语音识别）等，专为音频/语音任务设计。专门负责房子里的“耳朵”和“听觉”部分，比如麦克风阵列和语音处理系统。

所以如果你需要部署的模型只是纯文本模型的话，只需要安装 torch 即可，如果是图像/视频相关模型，还需要额外安装 torchvision，如果是音频/语音相关模型，则需要额外安装 torchaudio。如果是多模态的话，则三个都要装

> 注意：要安装的话，需要安装相同的版本系列，就像上面的命令一样

### HuggingFace相关

### 优化相关

#### vLLM

这是一个专门为大模型推理（特别是文本生成）而生的高性能服务框架。通过创新地使用了 `PagedAttention`技术，像操作系统管理内存一样管理显存，能有效减少显存碎片，让宝贵的显存资源利用率提升40%以上。这意味着在同样的硬件上能处理更多并发请求。通过动态批处理基础，可以自动合并多个请求，大幅提升吞吐量。各大云厂商的托管服务都深度集成了 vLLM，将其作为部署 LLM 推理服务的默认底座之一。它本身依赖于 PyTorch 作为其底层的计算引擎，负责执行模型的前向传播（即推理过程）

一般来说，如果只是希望上手尝试部署模型的话，可以不安装 vLLM

#### accelerate

`accelerate`是一个优化库，能在多 GPU 或混合精度等场景下，用更简单的代码获得更好的性能，也能更高效的利用显存

`pip install accelerate`

# 下载模型文件
安装好了相关依赖后，用一条命令 `hf download` 就可以下载模型了，但是在部署模型的时候，如果模型文件过大，很容易由于系统内存不足（OOM）导致进程被系统杀死，具体表现就是下载进度条会动，但是下载文件达到一定大小，内存放不下，就被杀掉了进程。

我觉得这其实很捞，因为 hf download 会在下载大文件的时候，将文件缓存在内存中再写入磁盘，这就导致一旦下载的速度过快，内存分配不及时很容易导致 OOM

可以通过 `aria2` 分段下载，这样基本上能一次成功

1. 首先通过 hf 的 dry-run 功能获取具体要安装的文件列表

```bash
hf download Qwen/Qwen2.5-7B-Instruct --dry-run 2>&1 | \
  grep -v '^Fetching' | \
  awk '{print $1}' > file_list.txt
```

2. 基本上上一步下载的文件中会有一些噪声，把 .gitattributes 之前的行删除，然后运行如下命令（注意替换对应目录路径），生成下载脚本，这个脚本会自动生成下载指定文件的 aria2 命令

```bash
python -c "
with open('file_list.txt', 'r') as f:
    files = [line.strip() for line in f if line.strip()]

repo_id = 'Qwen/Qwen2.5-7B-Instruct'
revision = 'main'
base_url = f'https://huggingface.co/{repo_id}/resolve/{revision}'
output_dir = '{项目目录}/models/qwen2.5-7b-instruct'

with open('download_aria2.sh', 'w') as out:
    out.write('#!/bin/bash\n')
    out.write('# 启用断点续传，限制全局并发为1，每个文件最多4个连接\n')
    for filename in files:
        # 对文件名进行URL编码，确保特殊字符（如空格）被正确处理
        # 但文件名通常不含空格，直接使用即可
        url = f'{base_url}/{filename}'
        cmd = f'aria2c -c -x 4 -s 4 -j 1 --out=\"{filename}\" --dir=\"{output_dir}\" \"{url}\"\n'
        out.write(cmd)
"
```

3. 生成脚本以后，加上可执行权限后，就可以跑起来了

```plain
chmod +x download_aria2.sh
./download_aria2.sh
```

# 测试模型

这个时候模型已经装好了（材料已经备好了），该有的环境也装好了（厨具也已经有了），现在就可以准备开始烹饪了！我们先小试牛刀一下，创建一个测试脚本 `test.py`：

## 测试脚本

```python
# 导入需要的依赖
import torch
from transformers import pipeline

# 指定你下载的模型路径
model_path = "{项目目录}/models/qwen2.5-7b-instruct"

# 创建文本生成管道，指定使用GPU (device=0)
pipe = pipeline(
    "text-generation",
    model=model_path,
    torch_dtype=torch.bfloat16,  # 使用bfloat16精度，这个看你显卡的显存大小
    device=0,                    # 指定使用 GPU
    trust_remote_code=True       # Qwen模型可能需要
)

# 输入提示词
messages = [
    {"role": "system", "content": "你是一个有用的助手。"},
    {"role": "user", "content": "你好，请介绍一下你自己。"}
]

# 生成回复
outputs = pipe(
    messages,
    max_new_tokens=512,
    do_sample=True,
    temperature=0.7,
)

print(outputs[0]["generated_text"][-1]["content"])
```

> 注意：trust_remote_code=True 警告：Qwen 系列模型包含自定义代码，设置这个参数是安全的，也是官方推荐的
